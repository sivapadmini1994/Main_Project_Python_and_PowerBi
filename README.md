# Hotel Booking Cancellation Prediction

## 📌 Project Overview
This project analyzes hotel booking data to predict cancellations using Python for data analysis/machine learning and Power BI for visualization.

## 📂 Dataset
- **hotel_bookings.csv** – Raw dataset
- **cleaned_hotel_booking.csv** – Cleaned & preprocessed dataset

## 🛠️ Tools & Technologies
- Python (Pandas, NumPy, Scikit-learn)
- Jupyter Notebook
- Power BI

## 🔍 Approach
1. Data cleaning and preprocessing
2. Exploratory Data Analysis (EDA)
3. Feature engineering
4. Model building for cancellation prediction
5. Power BI dashboard for visualization

## 📊 Key Insights
- Bookings made with longer lead times had higher cancellation rates.
- Resort hotels had lower cancellation rates compared to city hotels.
- Cusomers without deposit had higher chances of cancelling.
